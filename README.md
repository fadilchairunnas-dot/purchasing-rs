# Sistem Informasi Pengajuan dan Manajemen Stok Barang Rumah Sakit (Purchasing RS)

Repositori ini berisi rancangan sistem dan kode sumber untuk **Sistem Informasi Pengajuan dan Manajemen Stok Barang Rumah Sakit**, yang disusun untuk memenuhi penugasan mata kuliah Proyek Utama (Capstone Project) D4 TRPL Politeknik Negeri Padang.

## A. Identitas Proyek (T-03 System Request)
* **Nama Proyek:** Sistem Informasi Pengajuan dan Manajemen Stok Barang Rumah Sakit
* **Singkatan:** Purchasing RS[cite: 5]
* **Project Sponsor:** Yohadi Yoansyah (Kepala Sub Bagian Logistik)[cite: 5]
* **Mahasiswa Pengembang:** Muhammad Fadil Chairunnas (NIM: 2611089006)[cite: 5]

## B. Deskripsi Sistem
Aplikasi Purchasing RS adalah sistem informasi berbasis web yang dirancang untuk mendigitalisasi alur pengajuan dan pengelolaan stok barang dari berbagai unit kerja (seperti IGD, Laboratorium, Rawat Inap, dan Apotek) ke unit Purchasing Rumah Sakit secara transparan dan terintegrasi[cite: 5].

## C. Kebutuhan Bisnis (Business Need)
* Mengatasi risiko berkas fisik hilang atau terselip (5–10 formulir per bulan)[cite: 5].
* Menghilangkan keterlambatan informasi stok yang memicu penundaan pengadaan hingga 2–3 hari[cite: 5].
* Memberikan kepastian status pengajuan bagi unit kerja dan menekan *human error* pencatatan[cite: 5].

## D. Batasan Proyek (Scope and Boundaries)
* **Termasuk dalam proyek:** Autentikasi user & unit workstation, pengelolaan data barang/stok, form pengajuan real-time, dashboard admin, dan riwayat pengajuan[cite: 5].
* **TIDAK termasuk dalam proyek:** Transaksi keuangan/faktur akuntansi, integrasi otomatis ke vendor luar, pelacakan kurir berbasis GPS, laporan rugi-laba, dan aplikasi mobile native[cite: 5].

## E. Teknologi yang Digunakan
* **Backend & Frontend:** PHP Native, HTML5, CSS3[cite: 5]
* **Database:** MySQL (XAMPP Server Lokal)[cite: 5]
