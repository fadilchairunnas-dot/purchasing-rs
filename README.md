# Sistem Informasi Purchasing & Manajemen Stok - RS Mata SMEC Pekanbaru

Aplikasi berbasis web untuk mengelola proses pengadaan barang (purchasing), persetujuan admin, dan pemantauan stok operasional di RS Mata SMEC Pekanbaru.

## Fitur Utama
* **Autentikasi & Hak Akses (Role-Based):** Pemisahan akses antara Unit Pemohon dan Admin Purchasing.
* **Pengajuan Barang:** Form pengajuan kebutuhan logistik/medis secara digital.
* **Approval & Tracking Status:** Pemantauan status pengajuan (*Pending*, *Approved*, *Proses Pengiriman*, *Rejected*, *Selesai*).
* **Manajemen Stok:** Pencatatan keluar-masuk barang untuk mencegah kekosongan stok operasional.

## Teknologi yang Digunakan
* **Backend:** PHP Native
* **Database:** MySQL (XAMPP)
* **Frontend:** HTML5, CSS3

## Dokumentasi Pengujian
